# אפיון MVP — פלטפורמת קביעת תורים וניהול עסק

מסמך זה מרכז את היקף אבן דרך 1 (Milestone 1) ומהווה מקור אמת בתוך המאגר.
הספק המלא (18 אפוסים, 95 סיפורי משתמש) חי מחוץ למאגר. כאן נמצא התמצות שנבנה בפועל
ומה שנדחה לאבני דרך הבאות.

## קהל היעד

SaaS לעסקי שירות בישראל: מספרות, מספרות גברים, קוסמטיקאיות, מכוני יופי וציפורניים,
מאמנים אישיים, מספרות כלבים ועוד. הממשק כולו בעברית ומימין לשמאל (RTL).

## מחסנית טכנולוגית

- Next.js (App Router) + TypeScript
- Tailwind CSS מוגדר ל-RTL (`dir="rtl"`, `lang="he"`, תכונות לוגיות)
- Prisma ORM + PostgreSQL
- הזדהות: OTP לפי מספר טלפון מעל SMS. ספק ה-SMS מאחורי ממשק, עם מימוש קונסולה לפיתוח
  שמדפיס את הקוד ללוג בלבד. הקוד נשמר כ-hash עם תוקף ומסומן כנצרך (לעולם לא בטקסט גלוי).
- מוכן ל-PWA: web manifest + התקנה. דחיפת התראות מאחורי ממשק (stub) בשלב זה.

## מותג

שם המוצר הסופי נקבע בנפרד. השם מרוכז במודול יחיד `src/config/brand.ts` (`BRAND.name`),
ומוזכר משם בכל מקום (כותרת דף, header, PWA manifest, מיילים). החלפת השם = שינוי שורה אחת.

## היקף אבן דרך 1 — נבנה בפועל

### עמוד עסק ציבורי
לוגו, תמונת נושא, שם העסק, כתובת, תיאור, קישור לאינסטגרם; רשימת שירותים עם מחיר ומשך
שניתן להסתיר בנפרד; כפתור "קבעו תור"; ושורת קרדיט קטנה "פתחו עמוד כזה לעסק שלכם".

### זרימת הזמנה (stepper)
בחירת שירות(ים) ← בחירת איש צוות ← בחירת תאריך ← בחירת שעה (הצגת שעות פנויות) ←
סיכום ← אישור. כל שלב חוסם התקדמות עד להשלמתו; ניתן לחזור אחורה; משך כולל = סכום
השירותים שנבחרו. השעות הפנויות מחושבות משעות העבודה של איש הצוות פחות התורים הקיימים.

### הזדהות לקוח ב-OTP
בקשת קוד ← אימות ← עוגיית סשן.

### יומן ניהולי
תצוגת יום לפי איש צוות עם רשימת התורים, ופעולות ידניות ליצירה / אישור הגעה / ביטול.

### נתוני ליבה (seed)
עסק דמו, שני אנשי צוות, מספר שירותים, שעות עבודה וכמה תורים לדוגמה, כדי שהאפליקציה
תרוץ מיד.

### ממשקי ספקים (stubs)
SMS, Push ו-Payments מאחורי ממשקים עם מימושי פיתוח בלבד.

## מודל הנתונים (Prisma)

- **Business** — עסק (בעלים, שדות פרופיל, קשר להגדרות)
- **User** — משתמש (טלפון ייחודי, שם, תפקיד)
- **StaffMember** — מקשר User↔Business, רמת הרשאה
- **Service** — שירות (עסק, שם, `durationMin`, `priceAgorot`, `hidePrice`, `hideDuration`, `hidden`)
- **WorkingHours** — שעות עבודה (איש צוות או עסק, יום בשבוע, דקת התחלה/סיום, הפסקות)
- **Appointment** — תור (עסק, לקוח, איש צוות, שירות אחד או יותר, `startAt`, `endAt`, סטטוס)
- **Client** — לקוח (עסק, משתמש אופציונלי, שם, טלפון, הערות)
- **Reminder** — תזכורת (תור, `sendAt`, ערוץ, סטטוס)
- **OtpCode** — קוד חד-פעמי (טלפון, `codeHash`, `expiresAt`, `consumed`)
- **Settings** — מדיניות הזמנה ברמת עסק

**מוסכמות:** כסף כמספר שלם באגורות, משכים כמספר שלם בדקות, כל חותמות הזמן נשמרות ב-UTC.

**סטטוסי תור:** `PENDING` / `CONFIRMED` / `CANCELLED` / `DONE` / `NO_SHOW`.

**תפקידים:** `CLIENT`, `OWNER`, `STAFF`, `ADMIN` — הרשאות מדורגות (STAFF יכול להיות יומן בלבד).
