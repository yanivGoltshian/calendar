# מיתוג ושם למוצר

מסמך זה מציע שם מותג וזהות מותג בסיסית למוצר, יחד עם זמינות דומיין שאומתה מול whois.
כל שם, דומיין ופקודה מופיעים בשורה נפרדת או בבלוק קוד נפרד, כדי לשמור על קריאה נוחה מימין לשמאל.

## המוצר וקהל היעד

המוצר הוא מערכת לקביעת תורים אונליין ולניהול עסק מקצה לקצה, לעסקי שירות בישראל.
קהל היעד כולל מספרות, ספרים לגברים, קוסמטיקאיות, מכוני יופי וציפורניים, מאמנים אישיים ומספרות כלבים.
הקהל ישראלי ודובר עברית, וחלק גדול ממנו אינו קורא אנגלית.
לכן השם צריך להיות קצר, נעים להגייה בעברית, עתיר תנועות ובלי צרורות עיצורים קשים.
המשמעות באנגלית אינה חשובה, אבל השם אינו יכול להישמע שלילי או מביך בעברית.

## שיטת אימות הזמינות

לא הסתמכנו על רשומות DNS. דומיין יכול להיות רשום גם בלי שום רשומת DNS פעילה.
לכן כל זמינות אומתה ישירות מול whois, לפי הכללים הבאים.

עבור סיומת גלובלית בדקנו מול מרשם הרישום של Verisign, וחיפשנו את המחרוזת שמעידה על פנוי:

```
whois -h whois.verisign-grs.com "domain NAME.com"   # פנוי אם מופיע: No match for
```

עבור סיומת מקומית ישראלית בדקנו מול שרת ה whois של איגוד האינטרנט, וחיפשנו את המחרוזת שמעידה על פנוי:

```
whois -h whois.isoc.org.il NAME.co.il   # פנוי אם מופיע: No data was found
```

כדי למנוע תקיעה של whois במק, כל קריאה עוטפה במגן זמן:

```
perl -e 'alarm 8; exec @ARGV' whois DOMAIN
```

## רשימה מקוצרת של שמות מומלצים

לכל שם מצוין הכתיב הפונטי בעברית, תחושת המותג, והדומיין הזול ביותר שפנוי ואומת מול whois.
הרשימה מתמקדת בכיוון של משחק מילים עברית-אנגלית, שבו השם נשמע לועזי אך רומז ישירות לקביעת תור.

### 1. Torchick

השם:

```
Torchick
```

כתיב פונטי בעברית: תוֹרְצִ'יק

תחושה: תור בצ'יק, כלומר תור מהר. תור עם טוויסט אנגלי קליל, קצר ושובב, ותופס בסיס גלובלי אמיתי.

הדומיין הזול ביותר שפנוי:

```
torchick.com   (סיומת גלובלית)
```

## ההמלצה מספר 1

השם המומלץ:

```

```

```

```

כתיב מקומי חלופי לרישום הגנתי, שאומת כפנוי:

```
torchick.co.il
```

### נימוקים

צליל והגייה: שם קצר בן שתי הברות, עתיר תנועות ובלי צרורות עיצורים קשים.
כל דובר עברית הוגה אותו נכון בפעם הראשונה, גם מי שאינו קורא אנגלית.

זכירות ומשמעות: תור פלוס צ'יק, כלומר להזמין תור בצ'יק, מהר ובלי טרחה.
זה משחק מילים עברי אנגלי שמסביר את כל המוצר במילה אחת, ונצמד לזיכרון כבר אחרי שמיעה אחת.
המילה תור נמצאת בלב המוצר, והסיומת צ'יק מוסיפה אנרגיה, מהירות וחיוך.

זמינות ועלות: זהו דומיין com גלובלי ופנוי, נדיר לשם קצר וקליט, במחיר סטנדרטי וזול.
הבסיס הגלובלי מאפשר צמיחה מעבר לישראל, ובמקביל אפשר להחזיק גם את הכתיב המקומי לרישום הגנתי.

התאמה לעסקי שירות בישראל: השם אנרגטי, אנושי ומזמין, ועובד מצוין במסך קטן בטלפון שם רוב בעלי העסקים מנהלים את היומן.
הוא אינו מתנגש במותג ישראלי גדול קיים, ולכן ניתן לבעלות ולבידול.

הערה על חלופות: אם רוצים סלנג ישראלי טהור, yallator.co.il הוא חלופה חזקה שנשמעת "יאללה תור".
למי שמעדיף כיוון של יופי ופינוק, yoffi.co.il הוא כיוון חזק לתחום היופי והטיפוח.

## סקיצה של זהות מותג

זו סקיצה מילולית לכיוון, לא עיצוב סופי.

### כיוון צבע

הכיוון הנבחר הוא יוקרתי, חם ונקי: זהב על כחול מלכותי עמוק.
צבע ראשי: כחול נייבי מלכותי עמוק כרקע, שמשדר יציבות, אמון ומקצועיות, וגם רוגע ונעימות שמתאימים לעולם היופי והטיפוח.
גוון הזהב לקווי המתאר ולטקסט, ערך משוער:

```
#CEA24A
```

גוון הרקע הראשי, כחול נייבי עמוק, ערך משוער:

```
#0A182D
```

צבע רקע חלופי בהיר: קרם או חול, לשילוט ולכרטיסי ביקור על רקע נקי, עם אותו זהב.
ההיגיון: הזהב על הכחול העמוק נראה יוקרתי אך מזמין, מחמיא לסלון, למספרה ולסטודיו היופי, ונשאר קריא ומרשים גם בחותם עגול קטן וגם על שילוט גדול.

### קונספט לוגו

הכיוון הנבחר הוא אמבלם של יד שנוקשת באצבעות, שמתרגם ויזואלית את "בצ'יק", כלומר מהירות של רגע.
משני צדי היד מופיעות שתי מילים בעברית שמספרות את הסלוגן במבט אחד.
מצד ימין המילה תור, ומצד שמאל המילה צ'יק, באותיות עבריות כבדות וברורות, בהשראת הפונט:

```
Suez One
```

היד והטקסט בקווי זהב על רקע כחול נייבי עמוק, בתוך מסגרת עגולה עדינה עם נקודות יהלום קטנות על קווי ההפרדה, לתחושת חותם יוקרתי.
מעל היד מופיעה נגיעת ניצוץ זהובה, שמדגישה את רגע הנקישה והמהירות.
הלוגו כולו בעברית בלבד, בלי כיתוב באנגלית, כדי לדבר ישירות אל הקהל הישראלי.

לצד האמבלם קיים גם לוגוטייפ נקי: המילים תור צ'יק בפונט Suez One בזהב על כחול, עם הסלוגן להזמין תור בצ'יק מתחת.
התחושה הכוללת: יוקרתי, אנושי ומהיר, שעובד גם כחותם עגול קטן וגם כלוגו מלא על שילוט.
