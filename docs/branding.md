# מיתוג ושם למוצר

מסמך זה מציע שם מותג וזהות מותג בסיסית למוצר, יחד עם זמינות דומיין שאומתה מול whois.
כל שם, דומיין ופקודה מופיעים בשורה נפרדת או בבלוק קוד נפרד, כדי לשמור על קריאה נוחה מימין לשמאל.

## המוצר וקהל היעד

המוצר הוא מערכת לקביעת תורים אונליין ולניהול עסק מקצה לקצה, לעסקי שירות בישראל.
קהל היעד כולל מספרות, ספרים לגברים, קוסמטיקאיות, מכוני יופי וציפורניים, מאמנים אישיים ומספרות כלבים.
הקהל ישראלי ודובר עברית, וחלק גדול ממנו אינו קורא אנגלית.
לכן השם צריך להיות קצר, נעים להגייה בעברית, עתיר תנועות ובלי צרורות עיצורים קשים.
המשמעות באנגלית אינה חשובה, אבל השם אינו יכול להישמע שלילי או מביך בעברית.

## שיטת אימות הזמינות

לא הסתמכנו על רשומות DNS. דומיין יכול להיות רשום גם בלי שום רשומת DNS פעילה.
לכן כל זמינות אומתה ישירות מול whois, לפי הכללים הבאים.

עבור סיומת גלובלית בדקנו מול מרשם הרישום של Verisign, וחיפשנו את המחרוזת שמעידה על פנוי:

```
whois -h whois.verisign-grs.com "domain NAME.com"   # פנוי אם מופיע: No match for
```

עבור סיומת מקומית ישראלית בדקנו מול שרת ה whois של איגוד האינטרנט, וחיפשנו את המחרוזת שמעידה על פנוי:

```
whois -h whois.isoc.org.il NAME.co.il   # פנוי אם מופיע: No data was found
```

כדי למנוע תקיעה של whois במק, כל קריאה עוטפה במגן זמן:

```
perl -e 'alarm 8; exec @ARGV' whois DOMAIN
```

## רשימה מקוצרת של שמות מומלצים

הערה כללית על עלות: הסיומת הגלובלית היא הזולה והתקנית ביותר, והסיומת המקומית זולה גם היא ומשדרת זהות ישראלית.

## ההמלצה מספר 1

השם המומלץ:

```
Kefo
```

```

```

לצד הדומיין המקומי מומלץ לרשום גם את המקבילה הגלובלית, שגם היא אומתה כפנויה:

```
kefoli.com
```

### נימוקים

צליל והגייה: שתי הברות פתוחות ורכות, עתיר תנועות ובלי צרורות עיצורים.
כל דובר עברית הוגה אותו נכון בפעם הראשונה, כולל לקוחות שאינם קוראים אנגלית.

זכירות ומשמעות: השם רומז ל"כיף" בלי להיות מילה עברית מפורשת.
התחושה של הנאה ופינוק מתלבשת בדיוק על החוויה בעסקי היופי, הטיפוח והכושר, וגם מספרות הכלבים.

זמינות ועלות: הדומיין המקומי פנוי וזול, ומשדר זהות ישראלית שקרובה לקהל.
במקביל המקבילה הגלובלית פנויה גם היא, כך שאפשר להחזיק את שתי הסיומות בעלות נמוכה ולכוון הכל לאותו מותג.

התאמה לעסקי שירות בישראל: שם קצר, חם ואנושי, שעובד מצוין במסך קטן בטלפון, שם רוב בעלי העסקים מנהלים את היומן.
הוא אינו מתנגש במותג ישראלי גדול קיים, ולכן ניתן לבעלות ולבידול.

הערה על חלופה קרובה: השם פָּזוֹ חזק אף הוא, אך הוא קרוב מאוד למותג הדלק והקמעונאות הגדול פז, ולכן עלול להיתפס כנגזרת שלו.
בגלל זה בחרנו בקֶפוֹ כהמלצה הראשונה.

## סקיצה של זהות מותג

זו סקיצה מילולית לכיוון, לא עיצוב סופי.

### כיוון צבע

צבע ראשי: קורל חם או טרהקוטה רך, שמשדר חמימות, הנאה ופינוק.
צבע משני: שזיף עמוק או גרפיט, שמוסיף רצינות ואמון לצד הניהולי של המוצר.
צבע הדגשה: קרם או חול בהיר, לתחושת רוגע ופרימיום.
נגיעת רעננות אפשרית: מנטה עדין, לאיזון בין החם למקצועי.
ההיגיון: החם מייצג את חוויית הלקוח והכיף, והכהה מייצג את הכלי העסקי שמאחורי הקלעים.

### קונספט לוגו

מארק מילולי באותיות קטנות בסגנון סן סריף גיאומטרי ורך, עם קצוות מעוגלים וידידותיים.
האות העגולה בשם יכולה לרמוז לשעון עדין או לבועת אישור תור, וכך לחבר בין המותג לבין קביעת תורים.
קימור חיוך דק מתחת לשם מחזק את הרמז ל"כיף" ולתחושה הטובה.
אייקון לאפליקציה: ריבוע מעוגל בגוון קורל חם, ובתוכו אות פתיחה לבנה שהעיגול שלה נסגר לצורת וי של אישור.
התחושה הכוללת: חם, אנושי ונקי, שעובד היטב גם בגודל קטן על מסך הטלפון.
